# Component Contracts: SEO URL Input

This directory contains the behavioral contracts for components in the SEO URL Input feature.

## Components

1. **URLInputForm** - Main form component for URL input and submission
2. **LoadingIndicator** - Visual feedback during fetch operations
3. **ErrorDisplay** - User-friendly error message display
4. **SuccessMessage** - Success feedback after successful fetch

## Contract Purpose

Each contract defines:

- Component's public API (props)
- Expected behaviors
- State management responsibilities
- Accessibility requirements
- Integration points
