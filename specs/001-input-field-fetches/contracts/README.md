# API Contracts: SEO Analysis & Results Display

**Feature**: 001-input-field-fetches  
**Date**: 2025-10-26

## Overview

This directory contains API contract specifications for the SEO analysis feature. All contracts follow REST API conventions and are compatible with Next.js 14 App Router API routes.

## Contracts

- [analyze-seo-contract.md](./analyze-seo-contract.md) - Main SEO analysis API endpoint

## Contract Format

Each contract document includes:

- **Endpoint**: HTTP method and URL path
- **Description**: Purpose of the endpoint
- **Authentication**: Required auth (if any)
- **Request**: Request body schema and validation rules
- **Response**: Success and error response schemas
- **Status Codes**: HTTP status codes and meanings
- **Examples**: Request and response examples
- **Error Handling**: Common error scenarios
- **Performance**: Expected response time and timeouts
- **Dependencies**: External services or modules required
